# IN4200 – High-Performance Computing and Numerical Projects

**University of Oslo (UiO)**  
**Repository owner:** Zejing Wang

## Overview

This repository is intended for coursework, programming exercises, and numerical projects associated with **IN4200: High-Performance Computing and Numerical Projects**.

The focus is on the implementation and analysis of numerical computations, including how algorithms and software choices affect computational performance and scalability.

## Areas of Interest

Future work in this repository may cover:

- Numerical algorithms and scientific computing.
- Parallel and high-performance computing techniques.
- Performance measurement, benchmarking, and optimization.
- Computational efficiency, scalability, and numerical accuracy.
- Reproducible numerical experiments and technical documentation.

These topics describe the intended scope of the repository; no specific implementation is claimed at this stage.
